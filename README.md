# 🧮 Android-Style Calculator App (React)

A simple, responsive calculator app built with React, inspired by the default Android system calculator.  
It features a dark UI, blue and orange button scheme, and includes memory operations like `mc`, `m+`, `m−`, `mr`.

---

## ✨ Features

- Dark mode UI with clean layout
- Supports basic arithmetic: `+`, `-`, `×`, `÷`, `%`
- Functional memory keys: `mc`, `m+`, `m−`, `mr`
- Orange-highlighted operator keys
- Floating-style equal (`=`) button
- Clear (`AC`), backspace (`←`), and sign toggle (`+/-`) support
